### [CleanNote](https://github.com/CarlHatoum/CleanNote)
NLP pipeline that transforms raw clinical notes into structured JSON documents — symptoms, medical conclusions, treatments — using a local LLM (Mistral-7B-Instruct). Built during a research internship at the Hubert Curien Laboratory. Published at PFIA 2025 and available as an open-source Python package.

```bash
pip install -U cleanote
```

[GitHub](https://github.com/CarlHatoum/CleanNote) · [PyPI](https://pypi.org/project/cleanote/) · [Write-up](/posts/2025/07/cleannote-medical-nlp/)

### [LDPC Error Correcting Code](https://github.com/carlhatoum/LDPC)
Implementation of Low-Density Parity-Check (LDPC) error correcting algorithms in MATLAB. LDPC codes are used in modern communication standards: Wi-Fi, 5G, DVB.

### [Reinforcement Learning with OpenAI Gym](https://github.com/carlhatoum/reincorcement-learning-OpenAI-Gym)

### [Spotify Top 50 Analysis](https://github.com/carlhatoum/Spotify-TOP-50-songs)
Data analysis and visualization of Spotify's Top 50 dataset. Explores audio features (tempo, energy, danceability, valence) and correlations across top-charting tracks. Built with R and ggplot2.
